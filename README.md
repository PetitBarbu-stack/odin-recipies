Projet "recettes"

Il s'agit ici de valider des acquis "de base" du langage HTML 5 ; on crée un petit site qui contient trois recettes de cuisine, le but étant de développer tout ça, de le déposer correctement sur GitHub et de le faire tourner. Rien que du basique, donc.

Compétences : git, github, invite de commande Ubuntu, VS code basique (html 5)
